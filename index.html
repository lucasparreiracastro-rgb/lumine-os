Checklist de Segurança para Subir no Supabase (Passo a Passo Simples)

  1. Criar Projeto Gratuito no Supabase: Acesse supabase.com, crie o projeto Lumine-Caldas e salve a senha do banco.
  2. Ativar Autenticação por E-mail/Senha (Authentication → Providers): Desative "Allow new users to sign up" para ninguém de fora criar conta sozinho; cadastre manualmente apenas o seu e-mail e o dos autorizados (Monise / Vitor).
  3. Rodar o Script SQL abaixo no SQL Editor: Cria as tabelas com Row Level Security (RLS) ativo e a trava fitid VARCHAR(80) UNIQUE que impede extratos OFX duplicados no banco.
